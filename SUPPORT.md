# Support

Use [GitHub Issues](https://github.com/iamlyio/iamly-beacon/issues) for
reproducible bugs and public feature requests. Include the Beacon version,
operating system and architecture, the command that failed, and redacted error
output.

Do not include vault contents, tokens, private keys, customer data, or full
configuration files. Use [private vulnerability reporting](SECURITY.md) for
anything that may have security impact.

The open-source project is provided without a guaranteed response time. Product
and account support remain available through the support channel included with
your iamly.io service.
